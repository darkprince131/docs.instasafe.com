# Prerequisite

**Instasafe Secure Access**

- InstaSafe Secure Access License
- Network Infrastructure
- Identity and Access Management Integration
- Device Management
- Security Policies and Configurations
- Network and Traffic Segmentation
- Data Storage and Backup
- Admin and User Training

# Installation Steps

**InstaSafe Secure Access**

- Login to InstaSafe Secure Access
- Go to User and Group
- Go to User
- Add User
- Add Access Policy
- Go to Downloads
- Install Agent (Windows, Linux, MacOS, iOS, Android)
- Connect Agent
