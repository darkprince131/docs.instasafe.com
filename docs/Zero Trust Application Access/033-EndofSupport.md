**End of Support for Win7 (32 & 64 bit) InstaSafe Agent**

_Announced April 2022_

We are permanently removing support for agents running on Win7 (32 & 64 bit) effective from 30th Apr’22. End of support means that InstaSafe will not fix bugs related to agents running on Win7 (32 & 64 bit) and no new features will be available for use. We are making this decision to reduce development and support efforts on older versions of OS and speed up our ability to deliver market-driver features.

All the Windows 7 (32 & 64 bit) machines using agents needs to be upgraded to higher version of OS for better performance and reliability.

For any questions or concerns regarding this announcement, please email support@instasafe.com
