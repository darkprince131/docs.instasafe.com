## Security Question and Answer MFA

Security Question is a secondary authentication method that prompts users to answer one or more pre-configured questions to verify their identity. It serves as a fallback MFA option when access to mobile devices, email, or hardware tokens is unavailable.

### Preconditions

- Security Question must be enabled in the assigned Auth Profile.
 
- Users must have enrolled by selecting and answering the configured questions during from their profile.



## To Set or Update Security Question Answers

- Log in to the ZTAA Portal.

- Navigate to My Profile → Security Questions.

- Select questions and provide your answers.

- Click on submit answer to update the answers.

## Steps to Use

- Navigate to the ZTAA login page.
 
- Enter your username and complete Primary Authentication (e.g., password, AD, or SAML).
 
- On the Secondary Authentication screen, select Security Question.

<!-- paste image path according to url name "security-login-select.png" -->

- The system will present 1 to 3 configured questions (based on admin-defined settings).

<!-- paste image path according to url name "security-login-answer.png" -->

- Enter the correct answers in the input fields.

- Click Continue to complete the authentication process.
