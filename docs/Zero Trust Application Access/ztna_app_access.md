The InstaSafe ZTNA agent is a lightweight solution which provides secure access to network, web and RDP applications. The ZTNA client is compatible with Windows, Linux, and macOS, offering versatility across various operating systems. With low RAM consumption, it optimizes performance, particularly on systems with limited resources.

The steps to download and install the ZTNA agent are available [here](https://docs.instasafe.com/Zero%20Trust%20Application%20Access/ztnaagent/).

The benefit of using the ZTNA agent is that it can perform a [posture check on 17 device attributes](https://docs.instasafe.com/Zero%20Trust%20Application%20Access/deviceposture/) before granting access of applications to user.

The below video demonstrates the different features available in the ZTNA agent. As illustrated in the video:

- users can verify whether they have the latest version of the agent.
- users can verify the vpn connectivity status, health of the gateways and the applications which have been configured in the gateway.
- users can view a System Diagnostics report.
- users can open the agent and service logs for troubleshooting purpose.
- users can search for applications and also filter by application type (web, network & RDP).
- users can view their profile details.
