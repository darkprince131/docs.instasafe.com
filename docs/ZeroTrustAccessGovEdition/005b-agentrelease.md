InstaSafe ZTNA provides admins the ability to control the roll out of a particular version of Agent to users. 

- In case of roll out of a particular agent version, the admin has to push it out to users before they can be updated.To aid in convinient rollout and roll back of  updated agent version to end user

-  In case the admin needs to roll back to  a particular version, he can publish the earlier version  and the same will be rolled out to the Users. 

- The agent currently rolled out will be shown as rolled out and there will be a published option for rest.
