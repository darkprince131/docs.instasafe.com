## Filter Auth Chain 

InstaSafe ZTNA  besides enforcing strict access control can also restrict user access from certain IPs. The admin can blacklist or whitelist IP for individual user. Whitelisting will enable the user to login from the whitelisted IP and block access from all other IP's whereas blackisting will restrict access from a perticular IP only.

**IP based Filtering**

Steps to enable whitelisting and blackisting.

1- Go to Auth Profile tab from Identity Mangement section.

2-Select the Authentication profile for the User for whom you want to enable IP based filtering.

3- Go to Filter Auth Chain tab under individual auth profile. Check the  Filter Chain Auth option to enebae IP based filtering. 

4-Toggle the button for whitelisting or blackisting IP.Enter the IP and  click on Update.
